# WooCommerce XML Deep Surface V12 — 2026-10-01

Objective: recover real current Google Merchant XML URLs from the exact 30-site learning corpus.

Discovery sources are restricted to XML/feed URL evidence: current robots/sitemap/homepage/link surfaces, public search-index references, and exact historical XML references from Wayback when current discovery yields too few candidates. Every candidate is re-fetched against the current same host and must pass the strict Google Merchant payload validator.

No Store API, product extraction, plugin inference, browser automation, authentication, bypass/evasion, clearance replay, proxy rotation, or random-token enumeration is used.
