# Unified Scan Fabric

The project composes scan, audit, monitor, benchmark, migration, security, runtime and AI-assistance systems through shared evidence rather than separate authorities.

Flow: inventory -> risk partition -> fast breadth -> parallel lenses -> deep quality -> live runtime -> AI crossfire -> reconciliation -> receipt -> monitors.

Six analytical lenses: TypeScript breadth; Rust quality; Go fan-out; security; Cloudflare/runtime; policy/reconciliation.

The language policy is evidence-driven: Rust is used only for measured CPU/memory-sensitive deterministic kernels, Go only for measured high-concurrency/network utilities, while existing Python semantic/reference authority remains canonical until full promotion evidence exists.

A separate AI layer can use up to six independent provider/API lanes. Five successful independent lanes is the strong threshold. Provider shortages, quota failure, timeouts and missing credentials are recorded as limitations, never simulated as success.

Provider selection, privacy, quota, freshness, cost and capability stay inside the private Operations provider/task fabric. AI output is advisory and cannot certify truth, production readiness or policy compliance.

Read-only lanes may run concurrently. Writes, issue mutation, branch changes, merges, releases, policy changes and rollback stay serialized.

Every tracked inventory entry receives an explicit disposition and lens assignment. Unsupported types are delegated or explicitly marked not-applicable. A failed lane is an execution failure, not a zero-finding result.

One immutable snapshot, run ID, revision set, inventory hash and provenance packet are reused across compatible lanes. Reconciliation groups by invariant and preserves disagreement.

Cost control is map-first retrieval, deterministic summaries and risk partitioning before deep or AI analysis. Raw model transcripts are not retained unless required for debugging or audit retention.

The fabric does not move private code into Foundation, create a second deployment authority, expose secrets or let model scores become policy authority.
