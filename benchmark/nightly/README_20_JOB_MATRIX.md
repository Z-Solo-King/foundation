# Nightly 20-job research coverage

This is a coverage contract, not an execution claim. The intended overnight matrix is 19 materially different research jobs plus one artifact-only aggregator. It covers acquisition, public API/XHR, product identity, contradictions, price/stock freshness, pagination/sitemaps, image evidence, blocking, multilingual/community evidence, review poisoning, temporal isolation, multi-constraint comparisons, missing-data abstention, prompt-injection resistance, repository repair, VCS comparison, AI-assistant comparison, agent scaling, and self-audit.

All jobs are strict-$0 research/evaluation, require provenance, and prohibit production-control mutation. Chat records are candidate learning signals only. Hidden chain-of-thought is never collected.

The existing scheduled workflow currently executes two sequential four-slot research batches rather than this 20-job matrix. Therefore the matrix must not be represented as proof of 20 concurrent executions until the workflow itself is changed through its normal pull-request checks and the resulting run is observed.
