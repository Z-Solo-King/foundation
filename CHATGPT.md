# AI project adapter

Foundation and Operations share the Heroic AI project context. This file is a short adapter for AI sessions, not a product or runtime authority.

## Load order
1. \`docs/AI_AGENT_EXECUTION_POLICY.md\`
2. \`docs/CURRENT_SOURCE_OF_TRUTH.md\`
3. \`REPOSITORY_MAP.json\`
4. \`docs/FAMILY_ARCHITECTURE.md\`
5. the specific issue, contract, code path or runtime receipt required

Do not preload every documentation file.

## Session rule
Use current repository state and fresh tool evidence. Project/chat context is transport context, not proof.
GitHub and Cloudflare may be handled in one session when both connectors are available. Use separate chats when connectors are isolated or unreliable. Repository architecture does not depend on chat count.

## Research / audit
Prefer indexed retrieval, exact file/range reads, adaptive independent checks and root-cause clustering. Avoid replaying old session transcripts unless they contain unique historical evidence.

## Boundary
Foundation remains public-safe. Operations remains protected runtime/policy authority. Never move private secrets or runtime values into this public repository.
