# Foundation

Public contract core for the Z-Solo-King GitHub family.

This repository contains public-safe contracts, schemas, and reusable deterministic primitives. Protected execution, governance, evaluation holdouts, credentials, and promotion authority live outside this public repository.

## AI / human navigation

`AI_CODEMAP.json` is the compact machine-readable map of ownership, canonical modules, boundaries, and change methodology. Read it before scanning the repository broadly.
